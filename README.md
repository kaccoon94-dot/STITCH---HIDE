## 4. 주요 기능

- [맞춤 추천 시작 : 방문자는 사이트 곳곳의 맞춤 추천 버튼으로 맞춤 추천을 시작할 수 있다. GNB·플로팅 버튼·메인·라인업·상품 상세의 ★ 버튼 6개가 모두 P02 맞춤 추천으로 이어짐]
- [추천 조건 입력 : 방문자는 사용할 사람·포지션·손 길이·주로 던지는 손을 골라 추천 조건을 입력할 수 있다. 손 길이는 18~30 cm 슬라이더, 오른쪽 도움 영역에 손 길이 재는 법과 용어 설명]
- [아이 기준 추천 : 방문자는 '아이'를 골라 아이 기준으로 추천 조건을 입력할 수 있다. 아이 영역이 펼쳐지고 손 길이 10~18 cm, 나이 5~13세를 고르면 주니어 핏 글러브를 추천]
- [추천 결과 : 방문자는 입력한 조건에 맞는 글러브 크기와 모델을 추천 결과로 볼 수 있다. 포지션으로 모델을, 손 길이로 크기(±0.5인치)를, 던지는 손으로 착용 손을 정해 모델명·크기·가격을 보여 줌]

## 5. 트러블슈팅

 ### 이슈 1: 페이지 주소로 바로 들어가면 404가 나옴

  - **문제**: 배포 사이트에서 `/lineup`, `/product/...` 같은 주소를 직접 열거나 새로고침하면 GitHub Pages가 404를 응답함
  - **원인**: GitHub Pages에는 `index.html` 하나만 있었음. 주소 이동은 React Router가 브라우저 안에서만 처리해서, 서버는 `lineup` 같은 주소에 맞는 파일을 찾지 못했음
  - **해결**: 배포할 때 주소마다 실제 HTML 파일(`lineup.html`, `cart.html`, 상품 상세 6개 등)을 자동으로 만들도록 배포 설정(deploy.yml)을 고침. 상품 상세 파일은 상품 데이터의 id를 읽어 만들고, 목록에 없는 주소는 `404.html`로 앱을 보여 줌

  ### 이슈 2: 다시 배포한 뒤 흰 화면만 나옴

  - **문제**: 사이트를 다시 배포한 뒤 접속하면 화면이 비어 있음
  - **원인**: 브라우저에 남아 있던 예전 `index.html`이 재배포 때 지워진 예전 JS·CSS 파일(이름에 해시가 붙은 파일)을 불러오려다 404가 났음
  - **해결**: `index.html`에 스크립트를 넣어, JS·CSS 파일을 못 불러오면 한 번 새로고침해서 새 버전을 받게 함. 30초 안에 또 실패하면 다시 새로고침하지 않게 해서 새로고침이 끝없이 반복되지 않도록 함
