## 요약

- **이미 모바일 대응이 된 것 (4개):** 카드 3D 기울기(19), 돋보기(25)는 `pointer:fine` 조건으로 꺼져 있습니다. 슬라이더 −/+ 버튼(14)과 하단 비교 막대(23)는 모바일 전용으로 구현되어 있습니다.
- **손볼 것 (1순위)**
  - 공통 버튼, 칩, 푸터의 hover 효과(6·7·13): `(hover:hover)` 조건 없이 적용되어 있어 터치 후 hover 상태가 남을 수 있습니다.
  - P01 플로팅 버튼(10): 모바일에서 본문을 가리고, GNB의 '맞춤 추천'과 기능이 겹칩니다.
- **손볼 것 (2순위)**
  - 비교 표 가로 스크롤(24): 한 화면에서 비교하기 어렵습니다.
  - 브랜드 스토리 스크롤 등장(9): 1열 화면에서는 칸마다 대기가 생깁니다.
