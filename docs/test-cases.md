# STITCH & HIDE (스티치앤하이드) 테스트 케이스

- 프로젝트명: STITCH & HIDE (스티치앤하이드)
- 작성일: 2026-11-17
- 배포 주소: https://kaccoon94-dot.github.io/STITCH---HIDE/
- 기준 문서: `docs/prd.md`
- 환경: 공통 (모든 케이스는 prd.md '공통 검사 조건'에서 확인)
  - 지원 브라우저: 최신 버전의 Chrome·Edge(Windows), Safari(macOS·iOS), Chrome·삼성 인터넷(Android)
  - 화면 너비: 360px · 768px · 1024px · 1440px
  - 로딩 속도: 배포 주소의 P01을 Chrome Lighthouse 모바일 모드로 쟀을 때 LCP 2.5초 이하
- 읽는 법
  - 작은따옴표 안의 글자('맞춤 추천 시작하기' 등)는 화면에 보이는 버튼·메뉴 이름이고, 괄호 안의 ID(M-02, P01-S01-B01 등)는 prd.md의 화면 ID입니다.
  - GNB는 모든 페이지 맨 위의 메뉴 막대입니다. 메뉴 이름: 로고(M-01), '맞춤 추천'(M-02, 오른쪽 끝 강조 칸), '라인업'(M-03), '브랜드 스토리'(M-04), '장바구니'(M-05), '로그인'(M-06).
  - 페이지 주소: P01 메인 `/` · P02 맞춤 추천 `/recommend` · P03 라인업 `/lineup` · P04 상품 상세 `/product/:id` · P05 장바구니 `/cart` · P06 결제 `/checkout` · P07 로그인 `/login` (실제 주소는 배포 주소 뒤에 붙습니다. 예: `https://kaccoon94-dot.github.io/STITCH---HIDE/lineup`)
  - '처음 방문 상태'는 브라우저의 새 시크릿 창(Chrome: Ctrl+Shift+N)에서 배포 주소를 연 상태입니다. 장바구니에는 예시 2행(필드 핏 내야수 글러브, 주니어 핏 글러브)이 들어 있습니다.
  - 화면 너비 바꾸기(Chrome): F12로 개발자 도구를 열고 Ctrl+Shift+M(기기 툴바)을 누른 뒤, 위쪽 너비 칸에 숫자를 입력합니다.
