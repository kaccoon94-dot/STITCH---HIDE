## 1. 프로젝트 개요

### 목적
사회인 야구용 글러브를 소개하고 판매하는 브랜드 사이트입니다. 상품명·가격·사양·공방 이름은 모두 가상 데이터입니다.

### 방문자가 원하는 것
| 방문자 | 원하는 것 |
| --- | --- |
| 공통 | 내게 맞는 글러브 추천, 품질에 대한 확신, 쉽고 분명한 가격·라인업, 구매 후 관리 방법 |
| 글러브를 바꾸려는 경력자 (핵심) | 가죽·제작 상세 스펙, 모델 간 비교 |
| 사회인 야구 입문자 | 쉬운 용어 설명, 입문용 가격대 안내 |
| 아이 첫 글러브를 사는 부모 | 아이 나이·손 크기별 사이즈 안내, 안전·내구성 정보 |

### 핵심 행동
- **맞춤 추천 체험 완료**: 포지션·손 길이·주로 던지는 손을 고르면 맞는 글러브 크기와 모델을 추천받습니다.
- 보조 행동: 추천 받은 글러브 구매, 라인업·관리법 둘러보기
- 주요 동선: P01 메인 → P02 맞춤 추천 → P04 상품 상세 → P05 장바구니 → P06 결제

## 2. 요구사항

- 환경은 모두 공통입니다.
- 우선순위 기준: **상** = 안 되면 핵심 행동(맞춤 추천 체험 완료)을 못 함 / **중** = 보조 행동(구매·둘러보기)을 못 함 / **하** = 없어도 핵심·보조 행동은 가능
- 도착 화면이 같은 버튼은 한 줄로 묶었습니다.
