# STITCH & HIDE 페이지 구성

---

## 1. 확정한 내용

### 방문자 행동 기준 페이지 구성

| 방문자 행동 | 필요한 정보·기능 | 페이지 | 섹션 | 다음 행동 |
|---|---|---|---|---|
| 사이트에 처음 들어와 어떤 브랜드인지 파악한다 | 사이트 목적 한 문장, 맞춤 추천으로 가는 입구 | 메인 | 첫 화면 (한 문장 소개 + 추천 체험 버튼) | 맞춤 추천 시작 |
| 품질과 제작 방식을 믿을 수 있는지 확인한다 | 가죽·바느질 등 제작 이야기 (품질에 대한 확신) | 메인 | 브랜드 스토리 | 맞춤 추천 또는 라인업 |
| 내게 맞는 글러브를 추천받는다 **(가장 중요한 행동)** | 포지션·손 길이·주로 던지는 손 선택, 아이 기준 추천 (아이 나이·손 길이·주로 던지는 손), 쉬운 용어 설명 | 맞춤 추천 | 입력 단계 (용어 설명, 아이 기준 추천 포함) | 결과 확인 |
| 추천 결과를 확인한다 | 맞는 글러브 크기와 모델 | 맞춤 추천 | 결과 단계 | 상품 상세 확인 또는 장바구니 담기 |
| 라인업과 가격을 훑어보고 모델끼리 비교한다 | 쉽고 분명한 가격·라인업, 모델 간 비교, 입문용 가격대 안내 | 라인업 | 모델 목록, 모델 비교 | 상품 상세 확인 |
| 한 모델을 자세히 살펴본다 | 가죽·제작 상세 스펙, 안전·내구성 정보, 사이즈 정보, 쉬운 용어 설명 | 상품 상세 | 상세 스펙 (용어 설명 포함) | 장바구니 담기 |
| 구매 후 관리법을 확인한다 | 구매 후 관리 방법 | 상품 상세 | 관리법 | 장바구니 담기 |
| 담은 글러브를 확인한다 **(보조 행동: 구매)** | 장바구니 | 장바구니 | 담은 글러브 목록, 주문 금액 요약 | 결제 |
| 결제한다 **(보조 행동: 구매)** | 결제 | 결제 | 배송 정보, 결제 수단, 주문 요약, 주문 완료 | 관리법 안내 (상품 상세 > 관리법) |

### 페이지 목록

1. 메인 (첫 화면, 브랜드 스토리)
2. 맞춤 추천 (입력 단계, 결과 단계)
3. 라인업 (모델 목록, 모델 비교)
4. 상품 상세 (상세 스펙, 관리법)
5. 장바구니 (담은 글러브 목록, 주문 금액 요약)
6. 결제 (배송 정보, 결제 수단, 주문 요약, 주문 완료)

### 확정한 선택

| 항목 | 선택 | 내용 |
|---|---|---|
| A. 브랜드 스토리 위치 | 대안 2 | 독립 페이지 대신 메인의 한 섹션으로 둔다 |
| B. 용어 설명·관리법 위치 | 대안 2 | 용어 설명은 맞춤 추천과 상품 상세 안에, 관리법은 상품 상세 안에 나눠 배치한다. 가이드 페이지는 두지 않는다 |
| C. 모델 비교 위치 | 대안 1 | 라인업 페이지 안에서 비교한다 |
| D. 아이 사이즈 안내 위치 | 대안 1 | 아이 기준 추천을 맞춤 추천 체험 안에 넣는다 |
| E. 구매 방식 | 장바구니부터 결제까지 | 구매를 장바구니와 결제 두 페이지로 나눈다 |

## 2. 추후 결정에서 확정으로 바꾼 항목 (2026-11-12)

| 항목 | 확정한 내용 |
|---|---|
| 아이 기준 추천에 쓸 입력 항목 | 아이 나이, 손 길이, 주로 던지는 손 |
| 장바구니 페이지 안의 세부 섹션 | 담은 글러브 목록 (사이즈·주로 던지는 손 옵션 표시), 주문 금액 요약 |
| 결제 페이지 안의 세부 섹션 | 배송 정보, 결제 수단, 주문 요약 |
| 결제를 마친 뒤의 다음 행동 | 주문 완료 화면에서 관리법 안내로 연결 (상품 상세 > 관리법) |

- 남은 추후 결정 항목: 없음
