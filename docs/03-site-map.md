## 2. 사이트맵

```
STITCH & HIDE (스티치앤하이드)
│
├─ 01 메인
│   ├─ 첫 화면 ─ 사이트 목적 한 문장 소개 + 맞춤 추천 체험 버튼
│   └─ 브랜드 스토리 ─ 가죽·바느질 등 제작 이야기 (품질에 대한 확신)
│
├─ 02 맞춤 추천 ★ 가장 중요한 행동
│   ├─ 입력 단계 ─ 포지션·손 길이·주로 던지는 손 선택, 아이 기준 추천, 쉬운 용어 설명
│   │   └─ 아이 기준 추천 ─ 아이 나이·손 길이·주로 던지는 손 입력
│   └─ 결과 단계 ─ 맞는 글러브 크기와 모델 추천
│
├─ 03 라인업
│   ├─ 모델 목록 ─ 쉽고 분명한 가격·라인업, 입문용 가격대 안내
│   └─ 모델 비교 ─ 모델 간 비교
│
├─ 04 상품 상세
│   ├─ 상세 스펙 ─ 가죽·제작 상세 스펙, 안전·내구성, 사이즈 정보, 쉬운 용어 설명
│   └─ 관리법 ─ 구매 후 관리 방법
│
├─ 05 장바구니 (보조 행동: 구매)
│   ├─ 담은 글러브 목록 ─ 모델별 사이즈·주로 던지는 손 옵션 표시
│   └─ 주문 금액 요약 ─ 상품 금액·배송비·총 결제 금액
│
└─ 06 결제 (보조 행동: 구매)
    ├─ 배송 정보 ─ 받는 사람·연락처·주소
    ├─ 결제 수단 ─ 결제 방법 선택
    ├─ 주문 요약 ─ 주문 상품과 최종 금액 확인
    └─ 주문 완료 ─ 결제 완료 확인 → 다음 행동: 관리법 안내 (상품 상세 > 관리법)
```

## 3. 페이지별 구성

| 번호 | 페이지 | 섹션 | 섹션 내용 | 상태 |
|---|---|---|---|---|
| 01 | 메인 | 첫 화면 | 사이트 목적 한 문장 소개 + 맞춤 추천 체험 버튼 | 확정 |
| 01 | 메인 | 브랜드 스토리 | 가죽·바느질 등 제작 이야기 (품질에 대한 확신) | 확정 |
| 02 | 맞춤 추천 ★ | 입력 단계 | 포지션·손 길이·주로 던지는 손 선택, 아이 기준 추천, 쉬운 용어 설명 | 확정 |
| 02 | 맞춤 추천 ★ | 입력 단계 > 아이 기준 추천 | 아이 나이·손 길이·주로 던지는 손 입력 | 확정 |
| 02 | 맞춤 추천 ★ | 결과 단계 | 맞는 글러브 크기와 모델 추천 | 확정 |
| 03 | 라인업 | 모델 목록 | 쉽고 분명한 가격·라인업, 입문용 가격대 안내 | 확정 |
| 03 | 라인업 | 모델 비교 | 모델 간 비교 | 확정 |
| 04 | 상품 상세 | 상세 스펙 | 가죽·제작 상세 스펙, 안전·내구성, 사이즈 정보, 쉬운 용어 설명 | 확정 |

| 06 | 결제 | 주문 완료 | 결제 완료 확인 → 다음 행동: 관리법 안내 | 확정 |

## 4. 추후 결정에서 확정으로 바꾼 항목

| 이전 추후 결정 항목 | 확정한 내용 |
|---|---|
| 아이 기준 추천에 쓸 입력 항목 | 아이 나이, 손 길이, 주로 던지는 손 |
| 장바구니 페이지 안의 세부 섹션 | 담은 글러브 목록 (사이즈·주로 던지는 손 옵션 표시), 주문 금액 요약 |
| 결제 페이지 안의 세부 섹션 | 배송 정보, 결제 수단, 주문 요약 |
| 결제를 마친 뒤의 다음 행동 | 주문 완료 화면에서 관리법 안내로 연결 (상품 상세 > 관리법) |

- 남은 추후 결정 항목: 없음
