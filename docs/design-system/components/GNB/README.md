# GNB

모든 페이지 맨 위의 공통 메뉴입니다. 화면 폭을 다 채우지 않는 작은 막대가 `surface`(dark) 띠 위에 떠 있습니다.

- 칸 구성(왼쪽 → 오른쪽): 로고 칸 200px(M-01, 로고 160×36) | 메뉴 글자(M-03 라인업, M-04 브랜드 스토리, M-05 장바구니, 로그인) | 강조 칸 180px(M-02 맞춤 추천 ★).
- 막대: 최대 `nav-width` 920px, 높이 `nav-height` 64px, `surface-raised` + 1px `line`, `radius-md`. 칸 경계는 `line`.
- 메뉴 글자: `menu` 15px/500, `ink`, 사이 36px. 장바구니·로그인은 22px 선 아이콘 + 글자. 메뉴를 아이콘 뒤에 숨기지 않습니다.
- 강조 칸: `ember` 면, `on-ember` 글자 700 + 화살표. 맞춤 추천 페이지(P02)에서는 화살표 대신 6px 점으로 현재 위치를 표시합니다(`aria-current="page"`).
- 섹션 밝기와 상관없이 늘 dark 테마입니다.
- 로그인 메뉴는 사용자 요청으로 추가했고, 이동 목적지와 메뉴 ID는 [미정]입니다.
- 모바일: 햄버거 메뉴로 접되 M-02 '맞춤 추천'은 늘 보이게 둡니다.
