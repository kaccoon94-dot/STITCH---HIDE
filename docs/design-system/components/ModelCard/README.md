# ModelCard

글러브 모델을 보여 주는 테두리 카드입니다. P03 모델 카드와 P02 결과 카드가 같은 카드 언어를 씁니다.

- 공통: `surface-raised` + 1px `line`, `radius-md`, 그림자 없음. 위쪽에 모델명(왼쪽)·가격(오른쪽), 가운데에 배경을 지운 글러브 이미지.
- **작은 카드 (P03, light)**: 안쪽 20px. 모델명 `label`, 가격 15px `ink-soft` → 이미지 384×260 → 특징 태그(13px, 1px `line-strong`, `radius-sm`) → 아래 줄에 체크박스 '비교 담기' + 보조 버튼 '상세 보기'.
  - 마우스를 올리면 테두리가 `line-strong`으로 밝아지고 '상세 보기'가 `fill`로 채워집니다. 버튼은 평소에도 늘 보입니다.
- **큰 결과 카드 (P02-S02, dark)**: 머리 줄(모델명·가격 세리프 28px)과 본문을 `line`으로 나눕니다. 이미지 480×360 + 추천 크기(`heading`) + 설명(`body-sm`) + 버튼 묶음(장바구니 담기 주 / 상품 상세 보기 보조 / 다시 추천받기 텍스트).
- 소비자가 주는 것: 모델명, 가격, 이미지, 태그(포지션·크기·소재), 비교 담기 상태.
- 가격·사양은 가상 데이터입니다. 문서에 없는 할인가·별점·후기는 넣지 않습니다.
