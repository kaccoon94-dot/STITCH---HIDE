# Footer

모든 페이지 맨 아래의 공통 푸터(FTR)입니다. 왼쪽에 로고 자리, 오른쪽에 약관·안내 링크 2줄을 둡니다.

- 바탕 `surface-deep`, 위쪽 1px `line`. 안쪽 여백 위 40px, 아래 `space-48`. 본문 너비 `content-width`.
- 로고 자리: 160×36, 점선 1px `line-strong` 상자. 로고가 정해지면 GNB와 같은 로고로 바꿉니다.
- 링크: 14px, `ink-soft`, 구분점 `ink-muted`. 개인정보처리방침만 700으로 강조합니다.
- 1줄: 이용약관 · 개인정보처리방침 · 이용안내 / 2줄: 배송 안내 · 교환 및 반품 안내 · 고객센터.
- 링크 목적지는 [미정]입니다.
