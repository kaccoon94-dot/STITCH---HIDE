# HelpBox

어려운 용어를 그 자리에서 풀어 주는 상자입니다. P02 입력 화면 오른쪽, P04 스펙 표 옆, 결제 완료의 관리법 안내에 씁니다.

- 최대 400px, 안쪽 `space-32`, 1px `line`, `radius-md`. 면은 섹션 바탕(`surface`)과 같게 두고 테두리로만 구분합니다.
- 머리: 18px 정보 아이콘 + "용어 설명"(15px 700).
- 내용: 15px `ink-soft`, 줄 간격 1.8. 용어 이름은 `strong` `ink`. 항목 사이에 대시(`dash`)를 둡니다.
- 소비자가 주는 것: 용어와 설명 문장(기획 문서 문구 그대로).
