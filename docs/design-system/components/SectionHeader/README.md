# SectionHeader

섹션 머리 두 가지와 가상 데이터 안내 한 줄입니다.

- **가운데형 (P01)**: 영문 대제목 `display-wide`(자간 0.42em, 오른쪽 여백 -0.42em으로 중심 보정) + 부제 `body` `ink-muted`. 대제목과 다음 묶음 사이 `space-96`.
- **왼쪽형 (P02~P06)**: 짧은 선 28px + `eyebrow` 라벨 → 제목(`heading` 또는 페이지 제목은 `display-lg`). P03·P04는 오른쪽 끝에 짧은 설명(`body-sm` `ink-muted`, 최대 380px)을 아래 기준선에 맞춰 둡니다.
- **안내 한 줄**: 각 페이지 첫 섹션 위에 `caption` `ink-muted`. "콘텐츠 예시 · ○○는 가상 데이터입니다."
- 소비자가 주는 것: 제목, 라벨 문구, 설명.
- P03·P04 라벨 문구는 [미정]입니다. P02는 'STEP 1 · 조건 선택', 'STEP 2 · 추천 결과'를 제안 중입니다.
