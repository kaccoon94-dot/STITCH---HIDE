# HandSlider

손 길이를 고르는 슬라이더입니다. 현재 값을 오른쪽 위에 큰 세리프 숫자로 보여 줍니다.

- 소비자가 주는 것: 이름표, 최소·최대·기본값, 단계(0.5 cm).
  - 나: 15~23 cm, 기본 18.5 cm
  - 아이: 10~18 cm, 기본 15.0 cm
- 이름표는 `label`, 측정 기준은 괄호 안에 `ink-muted`로 함께 씁니다.
- 현재 값은 `output`, `heading-sm` 크기(28px) 세리프, 소수 첫째 자리까지 + " cm".
- 아래에 범위 끝값을 `caption`으로 양 끝에 둡니다.
- 트랙·손잡이 색은 `fill`. `ember`는 쓰지 않습니다.
- 모바일에서는 손잡이 44px 이상, −/+ 버튼을 함께 두는 방식을 검토합니다(6단계 반응형).
