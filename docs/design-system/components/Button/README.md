# Button

다섯 가지 버튼 종류를 모양으로 나누고, ★ 핵심 행동이면 색만 `ember`로 바꿉니다.

| 종류 | 모양 | ★ 아님 | ★일 때 |
| --- | --- | --- | --- |
| 주 버튼 | 면, `control-md` 56px, `radius-sm` | `fill` / `on-fill` | `ember` / `on-ember` + 오른쪽 화살표 |
| 어두운 배경 위 주 버튼 | 주 버튼과 같음, dark 섹션 | `fill`(Bone) / `on-fill` | `ember` + `shadow-ember` 빛 테, 첫 화면은 `control-lg` 60px |
| 보조 버튼 | 투명 면 + 1px `line-strong` 테두리, 글자 500 | `ink` | 쓰지 않음 |
| 텍스트 버튼 | 밑줄(offset 6px), 높이는 56px 터치 영역 유지 | `ink` | 글자 700 + 밑줄만 `ember` 2px (P04-S01-B02) |
| 동그란 플로팅 버튼 | `FloatingButton` 참고 | | |

- 소비자가 주는 것: 글자, 이동 목적지(`href`), ★ 여부. 아이콘은 ★ 다음 단계 화살표 하나만.
- 한 묶음에서 ★ 버튼은 하나, 맨 앞에 둡니다. 묶음 사이 `space-12`.
- 버튼은 늘 보이게 둡니다. 마우스를 올렸을 때만 나타나게 하지 않습니다.
- 버튼 글자는 동사로 끝냅니다. "맞춤 추천 시작하기", "장바구니 담기".
- 포커스: `focus` 2px 실선 + 2px 간격.
