# ImageSlot

사진이 정해지기 전에 크기만 잡아 두는 자리입니다(4단계 에셋 삽입에서 교체).

- `surface-sunken` 면, 모서리 `radius-none`, 왼쪽 또는 오른쪽 아래에 `slot` 캡션(12px `ink-faint`): "이미지 자리 가로×세로 · 사진 방향".
- `role="img"`와 `aria-label`로 무엇이 들어갈 자리인지 알립니다.
- 크기는 와이어프레임 그대로 씁니다. 예: 첫 화면 배경 1440×560, 격자 560×400, 결과 모델 480×360, 모델 카드 384×260, 측정 안내 400×240.
- 사진 방향은 README의 '이미지' 규칙을 따릅니다.
