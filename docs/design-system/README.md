STITCH & HIDE는 사회인 야구 글러브 브랜드 사이트입니다. 어둡고 묵직한 장인의 공방 분위기 위에, 처음 온 사람도 쉽게 고를 수 있는 친절함을 얹습니다. 이 시스템의 가장 중요한 규칙은 하나입니다. **엠버 색은 '맞춤 추천'으로 가는 ★ 핵심 행동에만 씁니다.**

## 말투

- 공방 장인이 처음 온 손님에게 차분히 설명하듯 씁니다. 짧고 정중한 '-습니다 / -세요'.
- 전문 용어는 쓰자마자 풀어 씁니다. "인치는 글러브의 크기를 나타내는 단위입니다."
- 과장, 감탄사, 할인몰식 표현("최저가", "지금 바로!"), 이모지는 쓰지 않습니다.
- 예시: "처음이셔도 괜찮습니다. 손 길이만 재 보시면, 맞는 크기를 함께 찾아 드릴게요."
- 실제 문구 예: "포지션과 손 길이, 주로 던지는 손만 고르면 내 손에 맞는 글러브 크기와 모델을 추천해 드립니다."
- 가상 데이터를 쓰는 화면은 첫 섹션 위에 `caption` 한 줄을 둡니다. "콘텐츠 예시 · ○○는 가상 데이터입니다."

## 색

- 두 테마는 **섹션 밝기**입니다. `dark`(Leather)는 분위기 섹션, `light`(Hide)는 입력·비교·구매 섹션에 씁니다. 섹션 요소에 `data-theme="dark"` 또는 `data-theme="light"`를 달면 그 안의 토큰이 바뀝니다.
  - dark: GNB, P01-S01 첫 화면, P01-S02 브랜드 스토리, P02-S02 결과 카드, P06-S04 주문 완료
  - light: P02-S01 입력, P03 라인업·비교, P04 스펙 표, P05 장바구니, P06-S01~S03
  - 푸터(FTR)는 늘 `surface-deep`입니다.
- 바탕은 `surface`, 그 위에 떠 있는 면(메뉴 막대, 카드, 폼 판, 도움 상자)은 `surface-raised`, 이미지 자리와 아이 기준 영역은 `surface-sunken`입니다.
- 글자는 `ink` → `ink-soft` → `ink-muted` 세 단계입니다. `ink-faint`는 교체 전 이미지 자리 캡션에만 씁니다.
- 면을 나누는 선은 `line`(1px), 누를 수 있는 것의 테두리는 `line-strong`입니다. 제목과 본문 사이의 짧은 대시는 `dash`입니다.
- **`ember`는 ★ 버튼 7개의 면에만** 씁니다(M-02, F-01, P01-S01-B01, P01-S02-B01, P02-S01-B01, P03-S01-B02, P04-S01-B02). 배경, 장식선, 아이콘, 링크, 글자색에는 쓰지 않습니다. 위 글자는 늘 `on-ember`(검정)입니다.
- ★가 아닌 주 버튼과 선택된 칩은 `fill` / `on-fill`입니다. 색이 아니라 모양으로 위계를 줍니다.
- 그림자는 쓰지 않고 테두리로 나눕니다. 예외는 `shadow-ember`(어두운 배경 위 ★ 주 버튼)와 `shadow-float`(플로팅 버튼) 둘뿐입니다.

## 글자

- 제목은 `serif`(Noto Serif KR 500), 본문·메뉴·버튼은 `sans`(Noto Sans KR)입니다. 둘 다 Google Fonts에서 불러옵니다.
- 위계: `display-xl` 44 → `display-lg`·`display-wide` 40 → `heading` 32 → `heading-sm` 28 → `cell-title` 24 → `body-lg` 18 → `body` 17 → `body-sm`·`label` 16 → `menu` 15 → `caption`·`eyebrow` 13.
- 큰 제목과 본문의 대비는 크게 두되, 읽는 글자는 13px 아래로 내리지 않습니다. 12px `slot`은 교체될 이미지 자리 캡션에만 씁니다.
- `display-wide`(자간 0.42em)는 "BRAND STORY" 같은 영문 대문자 섹션 대제목에만 씁니다. 가운데 정렬일 때 오른쪽 여백을 자간만큼 당겨(`margin-right: -0.42em`) 시각 중심을 맞춥니다.
- 글 칸은 "제목 2줄 → 짧은 대시 → 본문 2줄" 한 단위로 짧게 씁니다.

## 레이아웃

- 데스크톱 프레임은 1440px, 본문은 `content-width`(1200px)입니다. 좌우 최소 여백은 `space-24`입니다.
- P01 메인은 여백을 넓게 씁니다. 섹션 위아래 `space-160`, 큰 묶음 사이 `space-96`. 가운데 정렬입니다.
- P02~P06은 촘촘하게 씁니다. 섹션 위 `space-72`, 아래 `space-128`. 섹션 머리는 왼쪽 정렬이고, 제목 위에 짧은 선과 `eyebrow` 라벨을 둡니다(P03·P04는 오른쪽에 짧은 설명).
- 입력 화면은 왼쪽 입력 폼 판(`surface-raised`, 안쪽 `space-48`)과 오른쪽 도움 영역(400px)으로 나눕니다.
- 지그재그 격자는 560×400 칸 2열, 칸 사이 여백 없이 `line`으로만 나눕니다.

## 모양

- 모서리: 버튼·칩·입력칸·태그 `radius-sm`(4px), 카드·메뉴 막대·판 `radius-md`(6px), 사진 `radius-none`, 플로팅 버튼 `radius-full`.
- 버튼 높이: 기본 `control-md`(56px), 페이지의 첫 ★ 버튼 `control-lg`(60px), 칩·입력칸 `control-sm`(52px). 누를 곳은 44px 이상입니다.
- 버튼 종류 5가지는 **모양**으로 나누고, 색은 **★ 여부**로 정합니다. ★이면 어떤 종류든 `ember`, 아니면 무채색입니다.
- 다음 단계로 가는 ★ 버튼에만 오른쪽 화살표를 붙입니다.
- 키보드 포커스는 `focus` 색 2px 실선 + 2px 간격입니다.

## 이미지

- 첫 화면·상품 대표 사진: 검은 바탕에 가장자리와 바느질만 빛으로 드러나게. 상품 상세에서는 모양과 소재가 보이도록 조금 더 밝게.
- 브랜드 스토리·관리법: 손, 도구, 가죽 작업을 가까이 찍은 장면.
- 모델 카드: 배경을 지운 글러브.
- 사진이 들어오기 전에는 `ImageSlot`(회색 면 + 크기 캡션)으로 자리만 잡습니다.

## 아이콘과 로고

- 아이콘은 1.6~2px 선 아이콘(24 그리드, 둥근 끝)을 인라인 SVG로 그리고 `currentColor`를 따릅니다. 장바구니·로그인 22px, 화살표 16~18px. 이모지는 쓰지 않습니다.
- 로고는 아직 확정되지 않았습니다. 지금은 160×36 자리에 세리프 워드마크 "STITCH & HIDE"(자간 0.16em)와 바느질 점선 한 줄을 임시로 둡니다. 푸터는 점선 상자 자리 표시입니다.

## 하지 않는 것

- 다른 브랜드의 문구·로고·사진, 형광 다색, 고정폭 대문자, 격자 배경.
- 아주 작은 본문·메뉴 글자, 메뉴를 아이콘 뒤에 숨기기, 마우스를 올렸을 때만 버튼 보이기.
- 문서에 없는 가격·기능·후기 지어내기.
