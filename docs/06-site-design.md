# STITCH & HIDE 시각 디자인 기준

> 이 문서는 디자인 시스템 **STITCH & HIDE**(Claude 디자인 시스템 아티팩트)를 기준으로 사이트의 색·글자·여백·모양·컴포넌트 규칙을 정리합니다.
> 시스템의 값(토큰)과 이 문서가 다르면 **디자인 시스템이 우선**합니다. 값을 바꾸면 이 문서도 함께 고칩니다.
> 작성일: 2026-11-13 · 기준: `docs/01`~`05` 기획 문서, P01 메인·P02 맞춤 추천 시안(Claude Design 캔버스)

## 1. 핵심 원칙

1. **엠버 색은 ★ 핵심 행동 7개에만 씁니다.** M-02, F-01, P01-S01-B01, P01-S02-B01, P02-S01-B01, P03-S01-B02, P04-S01-B02. 배경·장식·아이콘·링크·글자색에는 쓰지 않습니다. (출처: 05-site-reference.md R3·R5)
2. **분위기 섹션은 어둡게, 입력·비교·구매 섹션은 밝게.** 두 밝기를 디자인 시스템의 두 테마(`dark` Leather / `light` Hide)로 나눕니다. (출처: 05-site-reference.md 제안 ⑤)
3. **위계는 색이 아니라 모양으로.** ★가 아닌 버튼과 선택 상태는 무채색 `fill`로만 구분합니다.
4. **그림자 대신 테두리.** 면은 1px 선으로 나누고, 그림자는 ★ 빛 테와 플로팅 버튼 두 곳에만 씁니다.
5. **친절하게 읽히는 크기.** 큰 제목과 본문의 대비는 크게 두되, 읽는 글자는 13px 아래로 내리지 않습니다. (출처: 05-site-reference.md 우선순위 표)

## 2. 색

### 2-1. 섹션 밝기와 테마

| 테마 | 쓰는 곳 |
| --- | --- |
| `dark` (Leather · 분위기) | GNB, P01-S01 첫 화면, P01-S02 브랜드 스토리, P02-S02 결과 카드, P06-S04 주문 완료 |
| `light` (Hide · 입력·구매) | P02-S01 입력, P03 라인업·비교, P04 스펙 표, P05 장바구니, P06-S01~S03 |
| 늘 고정 | FTR 푸터는 `surface-deep` |

- [미정] P04 상단 정보 영역·P04-S02 관리법의 밝기 (PROJECT_CONTEXT 9번 항목)

### 5-2. 버튼 5종류

버튼 종류는 **모양**으로, 색은 **★ 여부**로 정합니다. (버튼 종류 출처: 04-site-wireframe.md)

| 종류 | 모양 | ★ 아님 | ★일 때 |
| --- | --- | --- | --- |
| 주 버튼 | 면, 56px, 모서리 4px | `fill` / `on-fill` | `ember` / `on-ember` + 오른쪽 화살표 |
| 어두운 배경 위 주 버튼 | 주 버튼과 같음 | `fill`(밝은 색) / `on-fill` | `ember` + `shadow-ember`, 첫 화면은 60px |
| 보조 버튼 | 투명 면 + 1px `line-strong` | `ink` 글자 500 | 해당 없음 |
| 텍스트 버튼 | 밑줄(간격 6px), 터치 영역 56px | `ink` | 글자 700 + 밑줄만 `ember` 2px (P04-S01-B02) |
| 동그란 플로팅 버튼 | 지름 64px 원 | F-02 TOP: `surface-sunken` + `line-strong` 테두리 | F-01 추천: `ember` |

- 한 묶음에 ★ 버튼은 하나, 맨 앞에 둡니다. 버튼은 늘 보이게 둡니다.
- 포커스: `focus` 색 2px 실선 + 2px 간격.

## 6. 분위기와 말투

- 한 줄 설명: 공방 장인이 처음 온 손님에게 차분히 설명하듯, 짧고 정중한 '-습니다 / -세요'로 쓰고 전문 용어는 바로 풀어 씁니다.
- 예시 문장: "처음이셔도 괜찮습니다. 손 길이만 재 보시면, 맞는 크기를 함께 찾아 드릴게요."
- 와이어프레임 예시 문구는 그대로 씁니다. (출처: 04-site-wireframe.md)
- 쓰지 않는 것: 과장, 감탄사, 할인몰식 표현, 이모지.

## 7. 이미지와 아이콘
