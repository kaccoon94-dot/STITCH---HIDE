## 2. ID 규칙

| 대상 | 형식 | 예 |
|---|---|---|
| 공통 메뉴 | `GNB`, 메뉴 항목 `M-번호` | M-02 |
| 공통 푸터 | `FTR` | FTR |
| 플로팅 버튼 (메인) | `FLT`, 버튼 `F-번호` | F-01 |
| 페이지 | `P번호` | P02 |
| 섹션 | `페이지ID-S번호` (섹션 안의 하위 영역은 끝에 A) | P02-S01, P02-S01A |
| 버튼 | `섹션ID-B번호` | P02-S01-B01 |

- 같은 역할의 버튼이 여러 번 나오면 같은 ID를 씁니다 (예: 모델 카드마다 있는 P03-S01-B01 상세 보기).

### P01 메인 (위쪽 행 1)

레이아웃 참고: 전체 폭 어두운 첫 화면 → 가운데 정렬 섹션 대제목 → 이미지·글 지그재그 격자 → 가운데 정렬 마무리 문구 → 오른쪽 플로팅 버튼. 참고 이미지를 그대로 따르지 않고 지그재그는 2줄로 줄였으며, 공통 메뉴는 다른 페이지와 같게 유지했습니다.

**P01-S01 첫 화면** (전체 폭 1440×560)
- 배경: 전체 폭 어두운 이미지 X 상자 (1440×560)
- 왼쪽 위 안내: "콘텐츠 예시 · 문구와 공방 이름은 가상 데이터입니다."
- 가운데 정렬 (위에서 아래로)
  - 제목: "한 땀의 바느질과 엄선한 가죽으로, / 손에 길들수록 깊어지는 글러브를 만듭니다"
  - 구분 대시
  - 본문: "포지션과 손 길이, 주로 던지는 손만 고르면 / 내 손에 맞는 글러브 크기와 모델을 추천해 드립니다."
  - 버튼 P01-S01-B01 '맞춤 추천 시작하기' (어두운 배경 위 흰색 주 버튼, ★ 핵심 행동)

**P01-S02 브랜드 스토리** (모든 요소 가운데 정렬)
- 섹션 대제목: "BRAND STORY" (자간 넓은 영문)
- 부제: "손에 길들수록 깊어지는 글러브, 그 시작을 소개합니다"
- 지그재그 격자 (칸 560×400, 2열 × 2줄)
  - 1줄: 왼쪽 가죽·바느질 제작 이미지 X 상자 | 오른쪽 글 칸
    - "가죽의 질을 직접 확인하고, / 부위마다 알맞은 쓰임을 정합니다" — 구분 대시 — "재단부터 봉제, 끈 조립, 형태 잡기까지 / 한 단계씩 손으로 확인하며 완성합니다."
  - 2줄: 왼쪽 글 칸 | 오른쪽 장인 작업 이미지 X 상자
    - "사회인 야구 선수들의 손을 / 오래 지켜본 장인" — 구분 대시 — 큰 글씨 "STITCH & HIDE 공방" — "글러브 제작 장인"
- 마무리 문구: "처음 끼는 날보다 / 백 번째 경기에서 더 편한 글러브" — 구분 대시 — "글러브를 바꾸려는 경력자부터 입문자, 아이의 첫 글러브까지 / 각자의 손에 맞는 크기를 함께 찾아 드립니다."
- 버튼 (가운데): P01-S02-B01 '나에게 맞는 글러브 찾기' (주 버튼, ★ 핵심 행동), P01-S02-B02 '라인업 보기' (보조 버튼)

**FLT 플로팅 버튼** (메인에만 있음, 오른쪽 아래 고정)

### P02 맞춤 추천 (위쪽 행 2)

**P02-S01 입력 단계**
- 안내: "콘텐츠 예시 · 추천 상품명·크기·가격은 가상 데이터입니다."
- 제목: "내 손에 맞는 글러브를 찾아보세요"
- 본문: "사용할 사람, 포지션, 손 길이와 주로 던지는 손을 선택해 주세요."
- 왼쪽 입력 영역 (위에서 아래로)
  - 선택: '누가 쓸 글러브인가요?' — 나(선택됨) / 아이
  - 선택: '포지션' — 투수 / 내야수(선택됨) / 외야수 / 포수 / 1루수
  - 조절: '손 길이 (손목 주름 ~ 가운뎃손가락 끝)' 슬라이더, 현재 값 18.5 cm, 범위 15 cm ~ 23 cm
  - 선택: '주로 던지는 손' — 오른손(선택됨) / 왼손
  - **P02-S01A 아이 기준 추천** ('아이' 선택 시 표시, 연회색 영역)
    - 선택: '아이 나이' 드롭다운 — "나이를 선택해 주세요"
    - 조절: '손 길이' 슬라이더, 현재 값 15.0 cm, 범위 10 cm ~ 18 cm
    - 선택: '주로 던지는 손' — 오른손(선택됨) / 왼손
  - 버튼 P02-S01-B01 '추천 결과 보기' (주 버튼, ★ 핵심 행동)
- 오른쪽 도움 영역
  - 용어 설명 상자: "손 길이: 손목 주름부터 가운뎃손가락 끝까지 / 손을 편 상태에서 자로 측정해 주세요. / 오른손으로 던지면 왼손에 끼는 글러브를, / 왼손으로 던지면 오른손에 끼는 글러브를 / 선택합니다."
  - 손 길이 측정 안내: 이미지 X 상자 (400×240)

**P02-S02 결과 단계**
- 제목: "입력하신 조건에 맞는 추천 글러브"
- 입력 요약: 내야수 / 18.5 cm / 오른손 투구
- 추천 결과 카드
  - 왼쪽: 추천 모델 이미지 X 상자 (480×360)
  - 오른쪽: 추천 모델 "필드 핏 내야수 글러브", 추천 크기 "11.5인치 · 왼손 착용"
  - 설명: "내야수 · 손 길이 18.5 cm · 오른손 투구 기준의 추천 예시입니다. / 빠른 송구를 위한 공 꺼내기와 착용감을 살펴보세요. / 같은 손 길이여도 손 너비에 따라 착용감이 달라질 수 있습니다."
  - 가격: 189,000원
  - 버튼: P02-S02-B01 '상품 상세 보기' (보조 버튼), P02-S02-B02 '장바구니 담기' (주 버튼), P02-S02-B03 '다시 추천받기' (텍스트 버튼)

## 6. 기존 문서와의 연결

- 페이지와 섹션은 `docs/03-site-map.md`의 구성을 그대로 따랐습니다. 새 페이지나 섹션은 추가하지 않았습니다. 메인의 플로팅 버튼(FLT)은 섹션이 아닌 고정 버튼 묶음입니다.
- 상품 이름·가격·옵션 선택·장바구니 담기는 P04-S01 상세 스펙 섹션 위쪽에 두었습니다.
- `docs/02-site-structure.md`의 '다음 행동' 외에 새로 넣은 버튼은 다음과 같습니다.
  - P03-S01-B02 '맞춤 추천 받기', P04-S01-B02 '내게 맞는지 추천받기', F-01 '추천': 망설이는 방문자를 가장 중요한 행동(맞춤 추천 체험)으로 돌려보내기 위한 버튼
  - P02-S02-B03 '다시 추천받기', P05-S01-B01 '삭제', P05-S02-B02 '계속 둘러보기', P06-S04-B02 '메인으로', F-02 'TOP': 각 화면에서 필요한 기본 조작
